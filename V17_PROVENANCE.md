# V17 artifact provenance

V17 is an explicitly authorized diagnostic integration of the V12–V16 research. It retains the V11 CPI and legacy fallbacks, adds two frozen compact EPS tree ensembles, resolves supported task aliases using typed task semantics, and can extract next-quarter GAAP guidance from the supplied corpus. It makes no model API calls and imports no external evidence at inference time. Public evaluation answers were not used for fitting or calibration. The previous research promotion threshold was not passed; the user explicitly requested this diagnostic submission.

## Learned artifacts

Inherited artifacts and their licenses, input histories and availability guards remain as documented in [V8_PROVENANCE.md](V8_PROVENANCE.md) and [V11_PROVENANCE.md](V11_PROVENANCE.md). These are the EPS Huber model and the frozen CPI ensemble. Both are disclosed in the descriptor.

The new [EPS artifact](agent_submit_v17/eps_models.json) contains two non-neural histogram gradient boosting regressors: one pooled company expert, one bank expert. The immutable checksum, input-dataset checksums, scikit-learn version, training IDs, last label publication and complete export checks are recorded in [export-validation.json](research/v17-release/export-validation.json). Both experts are separately disclosed in `models[]` with the shared artifact checksum and their distinct names. The source and derived model artifacts use this repository's MIT license; third-party documents are not relicensed or redistributed in the image.

Fitting uses the existing V9 historical SEC EDGAR/Company Facts numerical EPS inputs, and the V15 fixed bank cohort. These are public numerical financial facts; source collection and first-filing availability handling inherit the V8/V9 research lineage. The pooled expert uses 11,833 rows from 400 issuers; the bank expert uses 507 rows from 19 issuers. Only labels published before 2022-01-01 are admitted. No stored company/task answer table is included in the image. The bank issuer list is routing metadata from the predeclared research cohort, not a prediction lookup.

Model form and hyperparameters come unchanged from the V12/V15/V16 comparisons. Model selection considered the already-consumed 2015–2021 development results; the last label publication in the complete selection universe is 2021-11-15. The artifact is applied only when the task cutoff is at least 2023-01-01, a conservative guard covering all fitting and selection data. Exported pure-Python inference matches scikit-learn on all 12,340 source rows and 3,600 exact/adjacent split probes. Inference features require only a pre-cutoff quarterly GAAP EPS pair and the task's supplied prior-year target-quarter EPS. V11 interval widths are retained; no public-unit outcome calibration is performed.

## Source-only guidance and task routing

[Guidance rules](agent_submit_v17/guidance_rules.py) preserve the V16 deterministic numeric candidates. The [runtime adapter](agent_submit_v17/guidance.py) accepts only supplied, entity-admitted, dated documents for the relevant quarter. It supports the validated TXN, QCOM and INTC source layouts, requires the target fiscal quarter/year and unadjusted/GAAP basis, and binds every citation to original character offsets. Annual, adjusted-only, ambiguous, conflicting, withdrawn, stale or future guidance falls back to the numerical forecast. The guidance method also uses the conservative 2023 availability guard because its selection considered the V16 historical development labels. Missing corpus guidance is never replaced by a stored external forecast. The historical source documents, research API responses and all NVIDIA credentials are excluded from the image and submission ZIP.

The [typed router](agent_submit_v17/routing.py) uses trusted task family, target type, permitted labels and explicit semantic quantity/operation descriptions. Corpus text cannot issue routing instructions. It preserves existing canonical routes and unknown targets. This implements the useful transfer finding from V13 without a neural dependency. V14's source-binding discipline is retained; its unsuccessful one-off corrections, free-form model forecasts and V15 market-context predictors are not active predictors.

## Validation and limitations

See [plan.json](research/v17-release/plan.json), [guidance-source-parity.json](research/v17-release/guidance-source-parity.json), [alias-validation.json](research/v17-release/alias-validation.json), [public-validation.json](research/v17-release/public-validation.json), and the [publication receipt](research/v17-release/publication.json) after CI finishes. Numerical research gains are conditional, measured on consumed historical development, and do not establish whole-track improvement. Official smoke checks are non-rankable. On the current public roster, only the two EPS units change numerical predictions; the public roster does not contain the three validated guidance issuers, so that upload alone cannot establish the V16 guidance effect. Reserved Treasury 2004–2012 and CPI 2017–2021 confirmation sets remain unopened.
