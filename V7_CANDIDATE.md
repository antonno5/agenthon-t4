# V7 — подготовленный диагностический кандидат

V7 собран, опубликован и упакован на cero. Он читает квартальные таблицы EPS и
проверяет несколько простых прогнозов по доступной прошлой истории. Вызовов
нейросети — **0**. Новая посылка на CodaBench **не выполнялась**.

Текущий подтверждённый результат V6: **0.4394** на лидерборде, **0.5586** по
внутренней шкале, 10/10 зачтённых задач. Цель **0.7** на лидерборде соответствует
примерно **0.7638** внутреннего балла. Проверки V7 пока не подтверждают такой рост.

## Что изменилось

| Область | V6 | V7 |
|---|---|---|
| EPS | Короткое числовое утверждение в тексте; часто возврат к прошлому году | Разбор квартальных GAAP-таблиц: знаки, убытки в скобках, годы и кварталы, текущий EPS и сопоставимый прошлогодний EPS |
| Прогноз EPS | Перенос доступного значения | EPS нужного квартала прошлого года + половина последнего годового изменения EPS |
| Аукционы, CPI | Фиксированное среднее | Выбор из нескольких простых правил только по завершённым прошлым окнам; минимум четыре окна и преимущество больше одной стандартной ошибки |
| COT | Продолжение последнего изменения | Такой же осторожный отбор с непересекающимися окнами; на открытом входе данных для замены V6 недостаточно |
| Ставки, кредит, пересмотры, реакция рынка | Правила V6 | Правила V6 |

Извлечение квартальных пар работает на всех **14/14** настоящих открытых отчётах
EPS. Нераспознанная или противоречивая таблица сохраняет результат V6. Прогнозы
руководства, скорректированный non-GAAP EPS и годовые суммы не принимаются за
квартальный GAAP EPS. Числа и ссылки берутся только из корпуса текущего задания.

## Отдельный исторический EPS-тест

Скачаны открытые SEC companyfacts для 25 компаний; после проверки дат и полноты
остались 24 компании. Development: 40 задач / 685 строк, 2012–2016. Отложенный
тест: 40 задач / 706 строк, 2017–2021. Всего 696 исходных наблюдений
«компания-квартал», из которых построено 1391 строка двух видов заданий.
Виды заданий используют общие наблюдения и не считаются независимыми выборками.

| Метрика на отложенном тесте | V6 | V7 |
|---|---:|---:|
| Средний локальный балл двух семейств, официальная формула | 0.5000 | 0.5118 |
| Точность направления EPS | 71.95% | 70.82% |
| MAE EPS в долларах на акцию | 0.9435 | 0.9076 |
| MAE роста EPS, процентные пункты | 106.84 | 83.70 |

MAE роста EPS снизилась на **21.7%**, но качество направления ухудшилось.
Разница среднего балла **+0.0118**; парный bootstrap по 20 кварталам даёт 95%-й
интервал **[-0.0331, +0.0554]**. Устойчивое общее преимущество не доказано.
Это результат отдельного EPS-стенда, не оценка всех семейств Track 4 и не прогноз
балла CodaBench. На development было 0.5396 против 0.5000.

Контейнер каждого кандидата видел только своё задание, без сети и правильных
ответов, с лимитами 2 CPU / 2 GiB. Использованы только сведения, поданные в SEC
к моменту прогноза. Целевые значения — первые опубликованные, а не поздние
пересмотры; самая поздняя использованная публикация — 2021-11-08.

Ограничения: текущая выгрузка SEC не является архивом API на каждую старую дату;
синтетические представления отчётов не измеряют извлечение из произвольных
документов. Локальный оценщик использует официальные формулы 5.2.2 и проверяет
точные цитаты; полного production verifier/NLI нет, `rankable=false`.

При разработке оценщика обнаружено неверное имя эталонного поля `label` вместо
`true_label`. Ошибочный development-отчёт сохранён отдельно. Исправление сделано
до запуска holdout; входы и прогнозы development побайтово не изменились.
Добавлен тест, который запрещает отсутствующую официальную метку.

Вспомогательный исторический повтор по открытым таблицам: CPI MAE 0.7687 → 0.7341
(66 строк); аукционы 0.09425 → 0.09466 (49 строк); COT без изменения (90 строк).
Это не независимый holdout и не сертифицированные исторические версии публикаций.
